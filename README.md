# 🍕 Pizza Ordering System

## Description
A desktop application built with C# and the .NET Framework designed for seamless pizza customization and order management. This project demonstrates event-driven programming, UI form controls, and real-time logic execution.

## Features
* **Custom Configuration:** Select pizza size, crust type, and multiple toppings.
* **Real-Time Calculation:** Dynamically updates the total price based on user selections.
* **Interactive UI:** Clean and user-friendly Graphical User Interface (GUI).

## Technologies Used
* C#
* .NET Framework
